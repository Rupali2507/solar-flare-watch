# 🌞 Solar Flare Forecasting and Nowcasting using HEL1OS & SOLEX Data

## Project Overview

Solar flares are sudden bursts of electromagnetic radiation released from the Sun due to magnetic reconnection in active regions. These events can significantly impact satellite operations, communication systems, navigation, and space-based technologies.

The primary objective of this project is to develop machine learning and deep learning models capable of forecasting and nowcasting solar flare activity using observational data collected by the **HEL1OS** and **SOLEX** payloads onboard **Aditya-L1**.

The available datasets include multiple scientific data products such as event lists, light curves, spectra, housekeeping telemetry, and Good Time Intervals (GTIs). Before building predictive models, it is essential to thoroughly understand the structure, quality, and scientific significance of each data product.

This notebook represents **Phase 0: Data Understanding**, where we systematically explore every available dataset to identify useful information for feature engineering and model development.

---

## Project Objectives

- Understand the structure of HEL1OS and SOLEX datasets.
- Explore different scientific data products generated by the instruments.
- Assess data quality and completeness.
- Identify features relevant to solar flare forecasting.
- Build a strong foundation for preprocessing, feature engineering, and machine learning.
